# Scripts

The legacy booking/chat data generators are deliberately disabled. They bypassed bed assignment and booking validation, and one could attach generated replies to real customer chats.

Use the local npm checks (`npm test`, `npm run typecheck`, `npm run lint`, `npm run build`) and the isolated-database checklist in [../ADMIN_WORKSPACE_ROLES_SETUP.md](../ADMIN_WORKSPACE_ROLES_SETUP.md) for phase verification.
